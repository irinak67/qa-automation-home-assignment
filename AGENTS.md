# Testing
 
- Do not add unrequested test scenarios. Suggest missing coverage and explain the risk it addresses.
- Do not weaken assertions, skip failing tests, or add retries just to make tests pass.
 
# Boundaries
 
- Do not edit files when answering questions or reviewing code unless changes are requested.
- Do not stage, commit, push, reset, or discard work without an explicit request.
- Do not read secret files or use real credentials or mailboxes without explicit permission.
